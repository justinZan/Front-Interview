## 每题怎样练

1. **限时 90 秒**：不看答案说出定义、业务场景、关键实现和边界。
2. **对照答案**：看是否遗漏“为什么、什么时候、风险是什么”。
3. **追问 2 分钟**：把题目放到能源设备后台场景，说明异常数据与用户可见结果。
4. **写自己的版本**：有项目经验就替换成真实项目；练习项目则明确说是模拟项目，不编造线上数据。

对问题的熟悉度可标记：`会解释`、`能写代码`、`能讲项目案例`。岗位核心题至少达到前两项。

## 三套模拟面试组合

### 第一套：基础与 Vue（约 45 分钟）

- 事件循环、Promise、请求竞态各选 1 题。
- TypeScript 类型设计、判别联合各选 1 题。
- Vue 3 响应式、watch 与 computed、组件通信各选 1 题。
- Pinia 状态边界、Vite 构建各选 1 题。
- 最后用 5 分钟说明一个设备管理页面的结构。

### 第二套：业务与实时（约 45 分钟）

- 菜单/按钮权限、表格筛选与分页、表单联调各选 1 题。
- WebSocket/SSE 选型、重连、快照增量与去重各选 1 题。
- ECharts 生命周期、图表空白排查、大屏适配各选 1 题。
- 最后画出“设备推送 → 状态归并 → 曲线与告警”的数据链路。

### 第三套：项目深挖（约 45 分钟）

- 3 分钟项目介绍，明确个人职责和结果。
- 面试官连续追问一次性能问题、一次线上故障、一次接口分歧。
- 说明最困难的取舍、验证证据和如果重做会如何改进。

## 笔试/现场编码练习

1. 预测一段含同步代码、Promise、`async/await`、定时器的输出顺序，并解释每一步。
2. 写 `DeviceStatus` 类型与映射函数，处理未知状态和 `null` 功率值。
3. 写设备列表请求逻辑，快速切换筛选时旧结果不能覆盖新结果。
4. 写一个 Vue 组件，监听容器尺寸，在挂载后初始化图表，卸载时销毁。
5. 实现实时事件归并：按事件 ID 去重，按设备序号拒绝旧状态，发现缺口返回“需要补拉”。
6. 设计三种角色的权限表，并说明前端按钮控制与后端接口鉴权的区别。
